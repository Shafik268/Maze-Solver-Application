# Maze-Solver-Application

# Maze Solver Using BFS and DFS

## Overview

This project implements a Maze Solver in C++ using Graph Data Structures.

The maze is represented as a graph where:

- Open cells are vertices
- Adjacent cells are connected using edges

The application finds a path from a start node to a destination node using:

- Breadth First Search (BFS)
- Depth First Search (DFS)

---

✅ Maze Representation using Graphs

## Input Example

```text
S 0 1 0
0 0 1 0
1 0 0 0
1 1 0 D
```

## Output Example

```text
BFS Path:

(0,0) -> (1,0) -> (1,1)
-> (2,1) -> (2,2)
-> (2,3) -> (3,3)
```
